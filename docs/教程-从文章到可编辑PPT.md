# 教程：从一篇文章到可编辑 PPT 的完整流程

> 本教程讲的是 neo_ppt_skills 的**主线流程**：先写文章，再拆分出页，然后逐页
> 生成图片，最后四层还原成可编辑 PPTX。全程走完，你会同时得到
> **图片型 PPT（好看）**和**可编辑 PPTX（能改）**两份成品。

---

## 流程总览

```
写文章（主题/受众/页数）
   ↓
拆分出页（页清单：每页标题+要点+视觉意图）
   ↓
逐页生成图片（GordenImagePPTGen：imagegen 出图 → 图片型 PPT）
   ↓
四层还原（GordenImage2PPTX：背景图/骨架图/元素图标/真文本 → 可编辑 PPTX）
   ↓
验收交付（双成品 + 渲染对照）
```

四步对应四个产出，缺一不可：

| 步骤 | 产出 | 谁来做 |
|---|---|---|
| 写文章 | 文章/大纲底稿 | 你（或 AI 辅助） |
| 拆分出页 | 页清单（每页标题/要点/版式） | 你 + AI |
| 生成图片 | 逐页 PNG + 图片型 PPT | imagegen（必须真实调用） |
| 转成 PPT | 可编辑 PPTX | GordenImage2PPTX 四层还原 |

---

## 第 0 步：环境准备

| 依赖 | 用途 | 说明 |
|---|---|---|
| Codex 宿主 + imagegen | 逐页生成图片 | **主线硬性要求**，无 imagegen 无法走主线 |
| Python 3.10+ | 运行脚本 | |
| `python-pptx` | PPT 生成与还原 | `pip install python-pptx` |
| LibreOffice | 渲染预览 | `soffice` 加入 PATH |

安装技能：把整个 `neo_ppt_skills/` 目录放入 AI Agent 的技能目录
（如 `~/.zcode/skills/`），目录名保持不变。

---

## 第 1 步：写文章

文章是整条流水线的源头——**文章结构直接决定 PPT 结构**。写之前先定四件事：

1. **主题**：一句话说清这份 PPT 讲什么；
2. **受众**：给谁看（领导汇报 / 客户提案 / 内训课件）；
3. **页数**：建议 12–20 页（含封面/目录/结尾），超过 25 页考虑拆分成两次汇报；
4. **每页角色**：封面 → 目录 → 章节页 → 内容页（叙述/数据/对比/流程）→ 结尾页。

写作要点：

- 每个章节对应 PPT 的一页或一组页，**要点控制在 3–5 条**；
- 数据（百分比、金额、排名）单独标出，后面做数据页用；
- 结论前置：先给答案，再给理由（金字塔原理）。

---

## 第 2 步：拆分出页

把文章拆成**页清单**。每一页写三样东西：

```markdown
### P05 客户分层的底层逻辑
- 页标题：客户分层的底层逻辑
- 要点：
  - 分层维度是"当前价值+未来潜力+战略匹配度"
  - 而非单纯的历史采购金额
- 视觉意图：左侧三维度卡片 + 右侧 2×2 四象限矩阵
```

**页型速查**（拆页时对号入座）：

| 页型 | 视觉意图 | 要点数 |
|---|---|---|
| 封面 | 大标题 + 副标题 | — |
| 目录 | 章节列表 | 全部章节 |
| 章节页 | 章节号 + 章节名 | — |
| 叙述页 | 段落 + 要点 | 3–5 条 |
| 数据页 | 柱图/漏斗/占比 + 大数字 | 1–3 组 |
| 对比页 | 左右两栏 + 维度行 | 3–5 行 |
| 流程页 | 箭头链 + 节点 | 3–6 步 |
| 结尾页 | 结论 + 行动号召 | 1–3 条 |

**拆页纪律**：

- 一页只讲一件事，讲透就走；
- 要点是短语不是长句（每条 ≤20 字），长句留给文章本身；
- 相邻页之间要有"为什么 → 怎么做"的逻辑衔接。

---

## 第 3 步：逐页生成图片（GordenImagePPTGen）

这一步把每页清单变成一张张精美的**整页图片**。

### 3.1 生成 outline.json

按页清单写 `outline.json`（每页：页码、标题、版式、全部文字内容）。
**每一页的真实文字必须全部写进 outline**——后面的图片提示词完全由它生成，
占位符和"此处省略"是红线。

### 3.2 逐页写提示词、调 imagegen

每页一次 imagegen 调用，提示词包含四段：

```
【版式】<布局描述，如"左文右图、上图下表">
【全部文字】<该页所有标题和正文，逐字，不可省略>
【风格】<配色、字体气质、装饰元素>
【比例】16:9
```

纪律：

- **每页都必须真实调用 imagegen**，源图保存在
  `$CODEX_HOME/generated_images/` 并复制到 `slides/NN-*.png`；
- 逐页记入 `imagegen-manifest.json`（generated_source + copied_to）；
- 生成后逐页检查：文字是否完整、有无乱码、版式是否跑偏，不合格重生成；
- 全部通过后合成为**图片型 PPT**（`out/<主题>-image-deck.pptx`）。

### 3.3 产出清单

```
<主题>/
├── outline.json
├── prompts/NN-*.md
├── slides/NN-*.png          # 每页成品图
├── imagegen-manifest.json
└── out/<主题>-image-deck.pptx
```

---

## 第 4 步：四层还原成可编辑 PPTX（GordenImage2PPTX）

这一步把每页 PNG **拆成四层**再合成可编辑 PPTX。

### 4.1 强制四层（从下到上）

| 层 | 内容 | 来源 |
|---|---|---|
| 背景图 | 页面底色、大面积装饰 | imagegen 提取式生成 |
| 骨架图 | 卡片、色块、线条框架（绿幕抠图） | imagegen 生成 + `chroma_key.py` 去底 |
| 元素图标 | 图标、小装饰（绿幕抠图） | imagegen 生成 + 去底 + `slice_grid.py` 切分 |
| 真文本 | 标题、正文（OCR 逐字） | AI 视觉提取，真文本框 |

**红线**：三层图片**必须** imagegen 提取式生成，逐页记入
`imagegen-assets-manifest.json`；用 PPT 色块重画、裁原图局部、省略骨架/图标
均属退化，发现即重做。

### 4.2 合成与验收

- `compose_pptx.py` 按 layout.json 合成四层 → 可编辑 PPTX；
- 文本框文字与原页图**逐字校验**；
- 交付双成品：图片型 PPT + 可编辑 PPTX。

---

## 第 5 步：验收

| 检查项 | 通过标准 |
|---|---|
| 图片型 PPT | 逐页好看，文字完整无乱码 |
| 可编辑 PPTX | 文本框可选中可修改，无占位符残留 |
| 渲染对照 | 可编辑版渲染与图片版并排比较，版式一致 |
| 双成品 | 图片型 + 可编辑同时交付 |

---

## 常见坑

1. **无 imagegen 硬走主线**——不行。宿主没有 imagegen 就停止主线，
   改用快线（合辑模板换字）或备线（矢量复刻），不得用代码绘图冒充出图；
2. **图片里文字缺字/错字**——imagegen 生成文字不稳定，提示词里文字要
   逐字给全，生成后逐字校对，错一个字就重生成该页；
3. **骨架图带了内容**——骨架图只画框架不画文字，文字全在真文本层；
   骨架图上出现文字就是提取失败，重做；
4. **只交图片型不交可编辑**——双成品缺一不可，"能看"和"能改"是两个交付物；
5. **封面双行标题只换一行**——模板类流程的常见叠字坑，两行都要替换。

## 附：快线（合辑模板换字）

如果只要"能编辑"不要"从零出图"，走快线（仅 python-pptx，分钟级出稿）：

```bash
# 1. 按主题搜页
python scripts/bank_all_cli.py find 客户分层
# 2. 查看槽位与容量
python scripts/bank_all_cli.py show 页码
# 3. 选页换字（输出 bank_all_out.pptx）
python scripts/bank_all_cli.py build 页码 "新标题"
```

edits.json schema 与 GordenPPTSkill 模式 A 一致，槽位与容量从对应
`detail.json` 查询。
