## 第3步：逐页手写SVG（核心技术规则速记，与规范冲突时以规范为准）
- viewBox `0 0 1280 720`；root：`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1280 720" lang="zh-CN" data-pptx-page-role="content|cover" font-family="Microsoft YaHei">`
- 页眉公式（正文页）：红/主色多边形角标 `<polygon points="0,0 80,0 64,52 0,52">` + 白字编号（衬线bold 27，font-family="SimSun, Microsoft YaHei"）+ 黑衬线bold标题26 + 主色细线y56。标题里的关键词可用tspan换主色。
- **每个语义单元一个根级 `<g id="描述名" data-pptx-bounds="x y w h">`，根组bounds互不重叠>1px（质检会fail）**。标题行宽=字数÷校准率×100，bounds比内容宽5%。
- 文本：一段一个`<text>`，多行用`<tspan x=同 x dy=正数>`；**行内强调用tspan**；字号：页标题26 卡头15-17 正文11.5-13 小字10-11
- ⚠️**中英混排（AUM/KPI/数字+汉字）的行防折行：行尾加零宽空格 `&#8203;`（U+200B，写XML实体）**——它计入导出框宽（约0.55em）但渲染零宽。~~行尾全角空格"　"已被证伪~~（导出器计其宽但UAX#14禁止在其前断行，净效果为零）。多行tspan的行尾U+200B可能自成空行顶开下一行，此时改用全角斜杠"／"或拆成纯中文/纯拉丁两个文本框。
- XML转义：`&`→`&amp;`，禁HTML实体（&nbsp;等），破折号—省略号·直接写Unicode。
- 基本形（rect圆角rect circle ellipse line）直接写；**箭头/雪佛龙/横幅/梯形等多边形轮廓必须用helper**：
```bash
python3 $SKILL/scripts/preset_shape_svg.py render-batch --input -   # JSON数组: preset/id/frame[x y w h]/fill/stroke/adjustments
```
输出片段原样插入，**绝不手写 data-pptx-authoring/prst/frame**。渐变/滤镜可直接写`<defs>`（2-3停linearGradient；softShadow: feDropShadow dx=0 dy=6 stdDeviation=8 opacity 0.10）。
- 图标：`<use data-icon="tabler-outline/users" x= y= width= height= fill="#HEX"/>`（必须有fill，禁stroke）；项目icons/里没有的不要用。
- **图标接口**：项目icons/缺图标时用 `python3 C:\Users\w\Documents\zcode_file\z\银行ppt\图片转PPT\fetch_icons.py <项目目录> tabler-outline/xxx simple-icons/yyy`——本地捆绑库有就复制，没有自动从iconify API拉取（200+图标集，含品牌logo：simple-icons/xiaohongshu、bilibili、sinaweibo、tiktok、kuaishou等）。**品牌logo禁止手绘近似**，一律走本接口拿官方图形。
- 背景：第一层 `<rect id="bg" data-pptx-role="background" x="0" y="0" width="1280" height="720" fill="#FFFFFF"/>`。装饰元素可作根图元 `id + data-pptx-role="decoration"`（免bounds、不算重叠）。
- **禁止**：class/style标签/mask/textPath/animate/script/foreignObject/HTML实体/把原图当图片层贴。摄影类内容才允许裁切原图嵌入`<image>`（本系列基本没有）。
- 每页写完先自查：bounds重叠？文字超界？混排行加空格没？
