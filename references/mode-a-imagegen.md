# 模式 A：imagegen 图片生成 — 提示词体系与执行要点

出图质量由提示词决定。本篇是模式 A 的完整方法论；SKILL.md 只保留工作流骨架。

## 1. 内容优先（最重要）

「排版太简单」几乎都是因为内容太薄——先备内容、再出图。一张内容页的基线：

- 1 句导语（含 2~3 个高亮关键词）
- **3~4 个并列模块/列**（而非 1~2 个）
- 每个模块内：模块标题 + **2~3 条要点** + **1 个特大号指标（带单位/说明）** + 1 个标签/进度条
- 1 条底部总结横幅
- 即一页 ≈ 4 模块 × (标题+2~3 要点+1 指标) ≈ **20+ 个文字信息点**

内容不足时**先把内容做厚**（补真实的子要点、指标、分类维度），而不是放大字号
填白；**绝不编造数据**——可补的是结构化拆解（如把"上市"拆成时间/募资额/意义），
不是虚构数值。内容写进 prompts/NN-*.md 的【页面文字】（逐字）再出图。

## 2. 复杂度强制清单

每张内容页至少包含下列 6 项中的 4 项（封面/结尾可少）：

1. **小节标题区**：左侧竖条/编号（01 / 1.1）+ 标题 + 短强调分割线
2. **一句导语**：关键词用强调色高亮
3. **中心高阶图表 或 多列模块**（见 §4 图表目录）
4. **模块内分层**：子标签横幅 + 要点列表（带小图标）+ 特大号重点数字
5. **微件**：标签药丸、进度条(带%)、连接线、指示箭头、环上节点编号
6. **底部总结横幅**：通栏色带放一句核心结论

"满而不乱"：重点数字最大、标题次之、正文最小，强调色只点睛不铺满。

## 3. 自包含提示词模板

逐页填写存 `prompts/NN-*.md`，必须自包含（不引用其它页，全部写死）：

```text
为我生成一张 <16:9> 横版演示幻灯片图片（宽屏高分辨率，上下留安全边）。
【整体风格】<风格 + 主色/辅色/强调色 HEX>
【本页角色】<封面/内容/章节页/结尾>
【核心信息】<本页要让人记住的一句话>
【版式结构】<落实复杂度清单：标题区+导语+中心图表/N列模块+模块分层+微件+底部横幅>
【图表形式】<按内容结构选 1 种主形式>
【页面文字（逐字照排，必须完全使用以下文字，不得改写、不得编造）】
  - 主标题：「…」 小节编号：…
  - 导语：「…」（关键词「…」强调色）
  - 模块：子标签「…」 标题「…」 要点「…」「…」 重点数字「…」 标签「…」
  - 底部横幅：「…」
【图标/装饰】<图标语义清单，扁平商务风，全套同风格>
【微件】<按需>
【字号层级】重点数字 > 主标题 > 模块标题 > 子标签 > 正文；标题≈正文 2.5–3 倍
【约束】无页码/logo/水印；中文标点；零拼写错误；避免大面积纯绿；满而不乱
```

出图后**禁止用代码在图上补字**；文字渲染有误就修订提示词重出该页。

## 4. 图表形式目录（结构 → 形式）

| 内容结构 | 推荐形式 |
|---|---|
| 顶层战略（愿景+支柱+地基） | 房子型架构图 |
| 统一策略/生态闭环 | 3D 莫比乌斯环、无限循环符号 |
| N 步循环 | N 节点莫比乌斯环/多边形闭环（中心核心图标） |
| 多要素并列总览 | Bento 便当盒看板（主单元更大） |
| 多维能力/评估 | 同心圆雷达扫描 |
| 分层体系/技术栈/架构 | 多层 3D 架构图（层间数据流） |
| 协同/双轮驱动 | 双圆交织、两环咬合 |
| 多引擎发力 | 三环重叠、多重同心圆 |
| 单指标/占比 | 半圆仪表盘、环形进度 |
| 问题诊断 | 鱼骨图 |
| 筛选/转化 | 漏斗图 |
| 现状评估 | SWOT 矩阵、四象限 |
| 线性增长/递进 | 3D 折叠彩带箭头、3D 阶梯 |
| 时间线/路线图 | 锯齿时间轴、里程碑路径 |
| KPI 总览 | 全景 Dashboard |
| 层级/优先级 | 金字塔、堆叠层 |
| 中心辐射 | Hub-Spoke 放射 |

同一套 PPT 内每页选不同形式；不要在图上标注形式名称。

## 5. 风格库

- **默认 luxury-dense**：深色/品牌色底 + 玻璃质感卡片 + 金色/霓虹强调 + 密集
  数据模块；或浅色高级杂志风（纯白/浅灰底 + 强对比标题 + 彩色强调块）。
- **tech-business（常用）**：浅色底(#F4F6F9) + 淡网格纹理；白色卡片（细投影
  圆角）+ 彩色标题条（红/藏青交替）+ 特大号红字指标 + 标签药丸 + 底部红色横幅。
- **备选**（用户点名才切）：极简（留白+单一强调色）/ 卡通（圆润撞色）/ 水墨
  （宣纸+晕染+印章红）/ 手绘 sketch / 科技蓝图（网格+电路线）/ 杂志编辑
  （强对比大标题）/ 暗黑大气。

切换时把基调写进模板【整体风格】，全套视觉语言保持一致。

## 6. 配色与字体

- 配色：主色 1 + 辅色 1–2 + 强调色 1，全套统一；**默认避免大面积纯绿**
  （模式 B 绿幕抠图会冲突）。
- 字体：中文微软雅黑/思源黑体风无衬线（国风可用楷/宋）；英文几何无衬线；
  标题加粗、字号为正文 2–3 倍；重点数字最大。

## 7. 大纲格式（A2 outline.json）

```json
[{
  "slide_number": 1,
  "title": "叙事化标题（非'关键数据'这类干标题）",
  "sub_title": "副标题/定位",
  "core_logic": "本页解决什么问题/展示什么逻辑",
  "visual_framework": "复杂框架名（全篇不重复）",
  "visual_generation_prompt": "纯画面描述：背景/框架结构/光照/数据视觉形态/质感，配色写死 hex",
  "detailed_content_paragraphs": ["深度长文×N：现状+痛点+真实数据 / 方案+步骤 / 回报+风险"],
  "visual_assets": {"icons": ["语义1", "…"], "background_texture": "网格/光晕…"}
}]
```

- `detailed_content_paragraphs` 是信息密度来源；出图时**蒸馏**成标题/要点/数字
  （逐字真实），不要把整段长文糊到图上。
- ⚠️ `visual_generation_prompt` 不含文字，**禁止单独出图**——必须与该页全部
  真实文字合并进 §3 模板。
- 标题叙事化（"用量 6 个月翻倍"而非"关键数据"）；避免"探索/深入/旅程/总而言之"
  等 AI 腔。

## 8. A4 执行要点

- 所有 prompts/NN-*.md 就位后再开跑；每页至少一次真实 imagegen 调用
- 失败/错字只重试该页；复制源图时保留 `$CODEX_HOME/generated_images/` 原图
- imagegen-manifest.json 逐页记录 `slide / prompt_file / generated_source /
  copied_to / backend`——这是模式 A 的验收证据
- 比例跟随用户（默认 16:9）；"必须 16:9 但后端只出 3:2"时按 16:9 安全构图
  生成后居中裁切，全套统一
