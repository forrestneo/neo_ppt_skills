# 编辑已有 PPT 的保真纪律（蒸馏自 dsh-ppt-canvas / dsh-ppt-maker / dsh-office-tools）

> 来源与许可：dsh-ppt-canvas（MIT）、dsh-ppt-maker（MIT, OMSociety）、dsh-office-tools（MIT, kw78）、
> dsh-ppt（MIT, stardustlc，双产物同源与收据思想）。
> 适用：模式 D（deck-all 换字）之外的一切"改别人的 .pptx"场景——改错字、更新数字、
> 局部重排。目标只有一个：**改完之后，没改的地方一个字节都不变，改的地方排版不乱**。

## 一、总原则（dsh-ppt-canvas 契约）

1. **编辑作用在解析出的原 XML 树上**——不是正则替换，也不是重建文件。不认识的
   属性、扩展、关系、母版引用自然全保留；正则在含中文/实体/转义的 XML 上会错拆。
2. **校验先于写入**：所有改动先在内存试算并整体校验，任何一条不合法整包拒绝、
   文件一个字节不动；拒绝时逐条给原因。
3. **未触碰部件字节级不变**：ZIP 层保留原始压缩字节，只重写被改的 slide 部件。
   有"未触碰页字节不变"的回归测试守着。
4. **op 字段白名单**：每种操作允许的字段显式列出，未列出的报错而不是静默生效。
5. **能力校验防"假成功"**：往表格/图表容器（graphicFrame）、组合（grpSp）里插填充
   会产出非法 OOXML——直接拒绝，**不能接口报 applied 而文件没变**。

## 二、文本编辑十二细则（每条都是真实"改一个字排版全乱"的根因）

1. **逐段沿用旧段落样式**：新段落 i 对应旧段落 i（越界沿用最后一段），**不是拿第一段
   当全局模板**——文本框常以空段开头，拿它当模板会把整框字号颜色对齐拉平成默认值。
2. **空段样式兜底链**：段首 run 的 rPr → 该段 `a:endParaRPr`（必须真带格式，只有 lang
   不算）→ 向后找最近带样式段 → 向前找 → 都没有才用默认。
3. **空行绝不带 run**：空文本 run 也会按继承字号把空行撑高一行，下面内容全被推下去。
   OOXML 里空行就是不带 run 的 `<a:p/>`。例外：原本有字的行被清空时，克隆
   endParaRPr 保住行高。
4. **逐字符样式映射用前缀/后缀 diff**：多 run 段落改文字时，算新旧文本最长公共
   前缀/后缀，未动部分各守原 run 样式，被替换区取**光标前一字符**的样式（PowerPoint
   插入语义）；连续同格式字符合并回一个 run。字符偏移 clamp 映射会在中间插入/删除
   时把后面样式整体推移一格——已废弃的做法。
5. **`a:endParaRPr` 必须维护**：它是 PowerPoint 记住"接下来输入的字"的格式的地方；
   给无 run 形状设样式时写进 endParaRPr/defRPr，否则下次输入回退旧样式。
6. **`xml:space="preserve"`**：文本首尾有空格必须写，否则空格被吃。
7. **字体同时写 `<a:latin>` 与 `<a:ea>`**：中文字形走 ea 槽，只写 latin 中文仍是旧字体。
8. **颜色子元素顺序固定**：solidFill 内先色值后变换——清空后按序重写，不就地替换。
9. **新填充插在 `<a:ln>` 之前**：CT_ShapeProperties 元素顺序固定（填充在描边前）。
10. **setLine"未提供的字段不动"**：只传 width 不能顺手删掉已有颜色——无条件
    removeChildren 曾让 `{width:3}` 把 #CCCCCC 静默变默认黑。
11. **duplicate 递归换新 id**：复制体里**每一个** `p:cNvPr` 都要新 id（取当前页最大
    id+1），只改外层会让子形状 id 与原件重复，PowerPoint 提示修复。
12. **Z 序插入位置**：新形状插在 `p:extLst` 之前（spTree 的 extLst 必须是最后一个子元素）；
    rotation=0 时删除 rot 属性而不是写 0。

## 三、占位符继承几何保护（局部修改不跑版的关键）

- 真实 PowerPoint 的占位符**没有 `<a:xfrm>`**——几何从 slideLayout → slideMaster 继承。
  无脑"补 xfrm"会把继承尺寸物化成 0×0，形状被压没。
- 规则：XML 有 xfrm 用 XML 的；没有就沿 slide→layout→master 逐级解析继承几何
  （键 `idx:<n>` 优先、`type:<t>` 兜底，只填空缺）；两级都没有**明确报错拒绝写入**，
  拒绝把形状重写为 0×0。
- move/resize/对齐/分布全部以"解析后的有效几何"为基线，不是以读到的（可能为空的）
  xfrm 为基线。母版 `p:txStyles` 的段落默认值（marL/indent/行距）也要承接，否则
  行距错、文字挤。

## 四、最小改动纪律（AI 协作约束）

- **只改用户要求的内容**：不顺手重排整页、不动未选中的元素；完成后一句话说明
  改了哪几个元素、改了什么。
- **先读后改**：改前读回结构（形状 bbox、层级、文本），改动落到具体元素 id；
  复杂方案先 dry-run 试算再落盘。
- 版式参数只换文字不碰坐标（deck-all 的 `--set 槽位=文字` 即此范式）；
  需要动几何时，以继承几何为基线显式设置，绝不"删掉让母版重算"。

## 五、无损撤销与冲突防护（dsh-ppt-canvas 一致性协议）

- **存字节不存 diff**：OOXML 补丁逆运算易失真（run 合并、样式继承），快照存写盘前的
  完整字节流，undo/redo = 字节回放；每文稿上限 50 步。
- **peek + commit 两段式**：先算要回放哪个快照，**写盘成功后**才推进游标与版本——
  写盘失败（文件被占用/磁盘满）时游标绝不能先动。
- **staleFile 防护**：落盘前对比磁盘 mtime 与打开时记录值，外部改过即拒绝覆盖；
  重开文件时若检测到外部修改，**清空撤销历史**（旧快照回放会覆盖别人的修改）。
- **原子写**：同目录临时文件 + rename；进程写一半被杀不会留下截断文件。
- 所有变更过**串行队列**，失败不断链。

## 六、双向性：逆向导入与手术式 patch（dsh-ppt-maker）

- `import`（.pptx → 中间格式）：所有样式解成 effective value 字面量，逆向方言是
  绝对几何的超集；L1 逐部件 sha1 校验 round-trip 全同。
- `patch`（手术式轻改）：库不建模的部件**原样保留**，返回 `lostParts` 清单——
  告诉用户哪些部件这次没保住，而不是静默丢弃。
- 工程防跑版：文件带 revision 乐观锁 + 产物 sha256，外部改过/记录缺失的成品
  **拒绝覆盖**，只能另存副本。

## 七、能力边界哲学（对用户诚实）

- 创建与更新是**两个契约**：创建允许生成新包；更新需要保留未知部件。没有对应
  能力就不提供该工具（dsh-office-tools 刻意不做 ppt_update）。
- 缺能力时返回明确原因（"本环境无二进制写入通道，嵌入图片不可用"），**不悄悄
  降级**（把嵌入改成链接、把截断标成完成）。
- 读任意真实 deck 时按 ZIP central directory 声明值先检查后解压（防 zip 炸弹）；
  超限明确报错而不是截断处理。
