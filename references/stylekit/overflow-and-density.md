# 防溢出与密度控制（蒸馏自 9 个 PPT 引擎的容量纪律）

> 来源与许可：pptwise（MIT）、PTT-Studio（MIT）、dsh-ppt-master（MIT）、dsh-ppt（MIT）、
> dsh-ppt-maker（MIT）、PPT-Design-Skill（MIT）、deepseek-design（Source Available，仅学习思想）。
> 与 `layout-engine.md`（审计阈值）互补：那篇管"怎么查出溢出"，这篇管"怎么从根上不溢出"。

## 一、双层容量模型（pptwise 核心架构）

- **编辑预算**（pacing）：dense / balanced / spacious 三档，决定"内容该有多少"——
  bullets 条数 6/5/4、每条宽度 27/25/22 units、body 基线 24/24/32px。
- **物理容量**（face）：当前版式盒子的实际装得下多少。
- **有效限制 = min(编辑预算, 物理容量)**，且 warn/error 双阈值：warn 是编辑性建议
  （"建议拆页"），error 是渲染安全（"会被截断"），**error 恒宽于 warn**——先警告
  拆页，还塞就到硬界真截断。
- 本技能已有同源实现：deck-all 的 `budget = 原文×1.1`（layout-engine.md 第二节）。
  新写文案时同样两问：预算允许吗？盒子装得下吗？取小者。

## 二、文本测量权重表（估算就偏保守）

| 来源 | CJK | ASCII/小写 | 特殊 |
|---|---|---|---|
| pptwise 标题 | **1.2** | 0.56 | 空格 0.3——标题权重偏大更安全 |
| pptwise 正文 | 1.0 | 0.56 | 与标题**两套独立权重**（防共享盲区） |
| layout_audit.py | 1.0 | 0.53 | 行高 1.25 |
| dsh-ppt | 1.0 | 0.55 | 标题宽限额按版式分档 40/24 字 |
| dsh-ppt-master | 1.0em | 0.58em | 大写 0.68、窄字符 0.34 |
| dsh-ppt-canvas | 1.0 | 0.55 | 行高 **1.35**（比 1.25 更保守） |
| PTT-Studio | 1.0 | 按字符表 | `mwMW@%`=0.85、大写数字=0.64、空格 0.28；**粗体 +6%**；opentype 真字体优先 |

**教训条目（pptwise）**：估算器与审计器曾共享同一无权重测量 → "审计全绿而
PowerPoint 里溢出"。修复法：**审计读导出器实际使用的字重/度量**。本技能对应做法：
layout_audit 用保守权重，最终以 LibreOffice 渲染目检为准，两者都过才算过。

## 三、防溢出降级链（顺序执行，禁止跳步）

pptwise 六步（渲染引擎级，写作时可借用其思想）：

1. **gap 阶梯收紧**：块间距 16→10→6px 逐档试排；
2. **块按比例让高**：单栏可收缩块让高，但每块有 minHeight 地板；
3. **拆分退化单栏**：双栏放不下→整页单栏重排（保住全部内容的单栏胜过丢内容的拆分）；
4. **跨行块改并排侧栏**；
5. **丢块必须显式声明**（data-dropped），**导出时拒绝整个文件**；
6. 字号收缩有地板（正文 24→16px、fit_size 底 9pt），地板到了就改内容而不是缩字。

写作侧三件套（dsh-ppt-master，直接可用）：

- **fit_size 回落**：从基准字号每次 −0.5pt 直到装得下，**底 9pt**——到 9pt 还装不下
  说明内容超版式容量，回去砍字。
- **砍字优先于缩字号**（两条独立来源）：整页文字 >380 字 warn，先砍字再想排版；
  "极简"不是页面未完成的借口，空白必须有职责（见第五节）。
- **孤字检测**（PTT-Studio）：末行只剩 1 个 CJK 字（或 1–3 字符短词）视为 fit 失败
  ——即使包围盒没溢出。deepseek-design 中文铁律：**末行"单字+标点"= 失败；修复
  靠重排行宽或删非必要措辞，不许缩全部正文字号、不许丢事实**。

## 四、密度上限表（超限先拆页）

| 维度 | 上限 | 来源 |
|---|---|---|
| 每页要点 | 1–8 条，**>5 条即 error 级**；中文每条 ≤20–24 字 | dsh-ppt / master / maker 三源一致 |
| 每页字数 | 正文区 ≤380 字 | dsh-ppt-master |
| 密度三档（light/medium/dense） | 标题 ≤16/20/24 字；要点 ≤3/5/8 条；每条 ≤15/30/60 字；正文 ≤50/150/300 字 | PTT-Studio |
| 表格 | ≤14 行、>6 列字号降至 14pt、每格 ≤60 字符、8 行自动续页重复表头 | dsh-ppt / master |
| 图表 | 类目 ≤8–10、折线 ≤8 系列、饼环 ≤5 片、雷达 3–8 维 | dsh-ppt-master |
| 形状数 | ≤50 个/页 | PPT-Design-Skill |
| 引用 | ≤3 行（含姓名/职务/机构） | PPT-Design-Skill |
| 节奏 | **连续 3 页同版式 → 换气**（插 kpi/chart/image/quote）；3 连同 kind 内容页 → 建议拆 | dsh-ppt-master / pptwise |

## 五、覆盖率与留白（防"整页空"与"整页满"两个极端）

- **覆盖率下限**（PTT-Studio，120×80 采样网格，装饰件**不计入**）：minimal 25% /
  simple 35% / balanced 45% / rich 55% / ornate 60%；cover/section/quote/全图页豁免。
- **版心 ≤70%**（dsh-ppt-master）：四边留白一致，内容区不铺满整页。
- **补满手法顺序**（PTT-Studio，禁止靠放大字号硬撑）：① 标题下加副标题句 →
  ② 3–5 张信息卡铺满 → ③ 底部结论条 → ④ 数字/编号/胶囊标签 → ⑤ 大配图（h≥60%）
  或 2×2 图格 → ⑥ 贯穿分隔线/时间线 → ⑦ 四角边带装饰。
- **留白必须有职责**（PPT-Design-Skill 双门标准）：焦点/节奏/层级/图片呼吸，四选一；
  无职责的空区 = 设计缺陷 = 打回，即使零重叠。

## 六、装饰宪法（装饰不抢内容）

| 规则 | 阈值 | 来源 |
|---|---|---|
| 每页装饰件数 | minimal 0–0 / simple 0–2 / balanced 1–4 / rich 3–8 / ornate 6–16；"一件"=成串记号算 1 | PTT-Studio / pptwise |
| 内容页装饰对比度 | 合成到页底色后 **<3:1**（退到内容之后）且 **>1.05**（保持可见），超了自动降透明度 | pptwise |
| 装饰压字 | 装饰在上层且与文字框相交 >**4%** 文字框面积 = error | PTT-Studio |
| 结构间距 | 装饰标记与版式家具（标题/页脚等）距离 <**24px** 就不画 | pptwise |
| 图片背景上写字 | 必须实采样：取最差 10% 像素算对比度；与中位色距离 >60 的杂乱像素 标题 >20% / 正文 >6% 即报 | PTT-Studio |
| 图片背景文字边距 | 文字离左右页边 ≥8%（装饰集中两侧，6% 安全边不够） | PTT-Studio |
| 华丽档配饰板 | ornate 档图片背景上的文字组必须有衬板（不透明度 ≥0.95） | PTT-Studio |

## 七、禁词汇表（生成侧源头拦截）

- **溢出代笔禁令**（pptwise validate 正则，命中即拒稿）：`+N 项…/more`、`另有 N 项`、
  省略号 `…`/`...`（代码块除外）——**页面上永不出现"另有 N 项"**，要么全量展示
  要么拆页；截断分 hard（必须改稿）/declared（明确声明的小字段）两级。
- **待填写禁令**：正文含"待填写/To fill"= error 阻断（结构模板产出草稿时必须
  显式标 draft，不冒充成品）。
- **空洞词审校**（dsh-ppt-master lintDeck）："分析/概述/背景/介绍/现状"结尾且 ≤10 字
  的标题 warn"无信息量"；"赋能/抓手/闭环/生态/打法/组合拳" info；标题必须是
  **可被反驳的结论句**。
- **数字纪律**：数字不写成句子，一律进 kpi/chart/table 并配 insight；一条要点 ≥3 个
  数字 warn 整页换版式；图表必须有 insight（有图无解 warn）。

## 八、执行顺序（写作时的心法）

1. 先按 `layout-library.md` 选版式并确认配额（第四节各上限）；
2. 按 pacing/密度档写内容量，预算 = min(档位预算, 盒子容量)；
3. 放不下走第三节降级链：砍字 → 拆页 → 降字号（≥地板）→ 仍不行退回重排结构；
4. 交付前过 `layout_audit.py` + 本文件第七节禁词自查 + `audit-protocol.md` 视觉门。
