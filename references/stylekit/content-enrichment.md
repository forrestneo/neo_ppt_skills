# 内容检索填充与去 AI 感（蒸馏自 ppt-generator-skill 等）

> 来源：SkillHub 社区技能 [ppt-generator-skill](https://skillhub.cn/skills/user_3b34947d/ppt-generator-skill)
> （pptxgenjs 路线的中文 PPT 助手，吸收其内容工作流与审美规则；结构对照参考）。
> 定位：`narrative-and-review.md` 管"怎么论证"，本篇管**内容从哪来、什么内容
> 一眼假**——主题只给一句话时的检索填充工作流，与"AI 感"禁止清单。

## 一、检索填充工作流（用户只给主题时的标准动作）

**第一步：识别内容缺口**（三种典型）：
- 只给了主题（"AI 发展趋势"）→ 需要检索详细内容；
- 只给了标题列表 → 需要补每条正文要点；
- 描述模糊 → 需要先明确行业/场景/受众，再检索。

**第二步：检索技巧**：
- 检索词 = `[主题] + 数据/报告/趋势/案例`；
- **优先权威机构数据**（Gartner、IDC、艾瑞、官方统计），来源写进来源行；
- 时效性内容优先最近 6 个月；
- **每个数字要有具体出处，查不到的不写**（与"数据零编造"铁律同源——宁可
  留占位提示也不编一个"4500 亿美元"）。

**第三步：填充原则（饱满度口径）**：
- 每个要点至少 2-3 句详细说明，不是光秃秃的短语；
- 要点须带具体数据/案例/解释支撑；
- 每页正文 80-150 字（对齐我们密度口径的阅读档下限；口播档减半，看场景）；
- 布局多样：同一种排版连用不超过 3 页（freelayout 引擎已内建此检查）。

## 二、"AI 感"禁止清单（生成前自检，交付前复查）

| 禁止 | 原因 |
|---|---|
| 纯文字页面（无任何视觉元素） | 演示不是文档 |
| **标题加下划线** | AI 感最强的单一特征；强调用字重/颜色/短线（0.9in 主色短线） |
| 默认蓝 #1E40AF 系配色 | "没设计过"的信号；走主题色系统 |
| 同一布局连用 >3 次 | 节奏单调（引擎警告） |
| 正文 <12pt | 可读性地板（铁律） |
| 文字与背景对比度不足 | 可读性（引擎 contrast 兜底已管） |
| 标题替观众"抖包袱"或"不是 X 而是 Y"式句型 | 反 AI 腔；标题写可被反驳的结论句 |
| 空洞词收尾的标题（分析/概述/介绍…） | 无信息量（lintDeck 规则已并） |

## 三、中文风格关键词路由（用户说"感觉"时对号入座）

用户往往说不出"四维参数"，说的是"莫兰迪""奶茶风""MUJI 感"。关键词→落点：

| 用户关键词 | 落点（本技能） |
|---|---|
| 商务/专业/汇报 | 主题 mckinsey-navy / blue-corporate；版式 bullets+table |
| 科技/深色/炫酷 | 主题 deep 色系（freelayout `dark: true` 深底页）；风格 dark-tech |
| 教育/清新/课件 | 主题 teal-fresh；密度 light（口播档） |
| 高端/黑金/奢华 | 主题 gold-champagne；装饰克制 ≤2 件 |
| 莫兰迪/学术/答辩 | 低饱和色（自定义 colors 传莫兰迪 hex 组）；版式 pyramid/compare |
| 校园/新生/Z 世代/可爱 | imagegen 风格走插画向（visual-styles 查插画系）；MBE 特征=白底黑描边+高饱和撞色 |
| 手账/治愈/复古 | imagegen 风格 paper texture + warm mood（style-dimensions 四维组合） |
| 极简/留白/高级 | 密度 minimal、版心 ≤70%、装饰 0-1 件、主题 graphite 系 |
| 小红书/ins 竖版 | 比例改 9:16（海报口径），版式 cards 单列 |
| 无印良品/MUJI | 米白底+单一酒红 accent、大量留白、无装饰 |

（23 套中文审美风格不必逐套建文件——落到"主题色 × 密度 × 装饰预算 × imagegen
纹理"四个已有旋钮的组合，见 `style-dimensions.md` 四维系统。）

## 四、交互别名（中文指令的礼貌层）

用户说的 → 执行的动作：
- "做 PPT [主题]" → 模式 C/E 流程起点；
- "改第 N 页" → 定位单页重生成（不整卷重跑）；
- "换个配色" → 只换主题色重出（deck-all `--theme` / freelayout `--theme`）；
- "预览" → 渲染 PNG 联络表交付；
- 一次问清需求（主题/页数/用途/语言），**没给的用默认值并在交付时说明**——
  页数默认 10、风格默认简约商务、语言跟随用户。
