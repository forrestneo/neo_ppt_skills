# 内容保真与自评门禁（蒸馏自 luobo-ppt，MIT, zhouluobo）

> 来源：[luobo-ppt](https://github.com/zhouwei713/luobo-ppt)（MIT License, Copyright (c)
> 2026 zhouluobo）。定位：`audit-protocol.md` 管"排版验收"，本篇管**内容层**——
> 改稿/美化时文字意思不许变、QA 机制不许自欺、交付前审美自评怎么打分。
> 它最有名的一句话：**"正文逐字都对的稿子，意思常常就变在小字上。"**

## 一、安静的改动（五类，单独设门禁）

图表周围的每个字都对，但图的意思变了——这些改动不藏在正文里，必须单独核对：

| 安静的改动 | 后果 |
|---|---|
| 删掉数字格式（35% 显示成 35） | 单位丢了 |
| 删掉坐标轴标题（"单位：万元"） | 量纲丢了 |
| 改了数据值（哪怕 1%） | 结论可能反转 |
| 去掉脚注星号（"复购率 25%※"） | 口径免责丢了 |
| 图表页改成列表页型（文字都在） | **图没了** |

**双层比对法**：严格层只去空白和加粗标记、引号归一（**不删任何符号**）；宽松层
才允许吃掉星号等列表残渣。严格层不过而宽松层过 = "小字被改了" = 拦下。
配套核对清单（交付前固定动作）：每个图表的类别/系列名/数字显示样例（带不带单位）/
图表标题/坐标轴标题 + 每条注释、来源、单位说明、带 * ※ 的小字，**左边原稿右边
成品逐项对**。数字格式要按 Excel 语义复刻显示（ROUND_HALF_UP、百分号 ×100、
引号字面量），不是简单字符串比对。

**小字识别**：行首 `* ※ † ‡ 注 备注 说明 来源 数据来源 单位 口径 source note unit`
即小字；脚注标 `*※†‡` 粘在数字/词尾（故意不含上标数字——数学稿 x³ 远比编号脚注
常见）。原稿页脚的来源/脚注要进专用槽位（合成一行 `※ 未经审计　来源：财务部`）。

## 二、QA 机制不许自欺（防作弊三设计）

1. **报告先删后写**：QA 报告在检查前先删除——崩溃就不留旧报告，绝不把上次的
   干净报告错当本次结果；评审脚本还要校验报告 mtime 新于版面 dump，过期 = "QA
   没跑完，先重跑"。
2. **退出码三态**：0=无 ERROR / 1=有 ERROR / 2=QA 自身崩溃——崩溃≠通过。
3. **ERROR 清零才交付**，任何模式（快速模式、用户不在场）都不跳过逐字核对与 QA。
   逐字比对的**负号保护**：`-` 后必须有空格才当列表符删（`-5°C`、`−5°C` 必须原样保留）。

## 三、五维自评（审美层，QA 管不到的）

QA 只管机械问题；整套像不像一个人做的、翻页有没有起伏，要靠看渲染图打分。
**每维 0-10 分，五项各算各的，不许取平均**（"统一 9 分、节奏 4 分"是合法且常见的）。
每维一张机器证据表留给人打分：

| 维度 | 机器证据与阈值 |
|---|---|
| 统一 | 全篇字号种数 ≤8 好、>10 散；字体角色分布（display 只许出现在封面/大数字/章节号）；色板外颜色数应为 0；卡片圆角 1~2 种 |
| 层级 | 逐页"最大字号/中位字号"比值 **<1.5 的页列为弱页**；单页 >5 种字号弱 |
| 细节 | near-miss 清单：左边缘差 **0.03~0.18 in 的"差一点没对齐"**多半是失误；对比度/越线/强调色超量警告优先 |
| 传达 | 屏幕字数 >160 的页（拆页或换结构版式）；标题平均字数（结论式标题 10–20 字）；要求口播的内容页缺备注 |
| 节奏 | 版式种数/页数 ≥一半；**连续三页同版式**；字数起伏（标准差/均值在 **0.3~0.7** 有呼吸感） |

产出三清单：**保留 / 要修 / 顺手改**——"要修"交付前改掉（改完重跑全管线，
**最多三轮**），"顺手改"写进交付说明不动手。常见改法对照：字号碎→同类文字统一
字号档；层级平→换大数字/宣言页；连续卡片→插大字页/图表/章节页换气；强调色多→
只留一处。

## 四、大纲门禁（写内容时的机器可查检查）

- **结论式标题的程序化判定**：标题以话题词结尾（介绍/概述/总结/背景/优势/方法/
  原理/现状/分析/要点/内容/问题/结论/谢谢…20 词）且总长 ≤词长+6 → WARN"这是
  话题名不是结论"；"什么是/如何/怎么"开头 ≤8 字无标点 → WARN；长度 4–22 字。
- **幽灵稿自检**：把全部标题按序连读——**应是一个完整的故事**，读不通先调结构
  再设计。"只读标题"清单发给用户确认后才进设计。
- **密度两档**：口播/演讲 ≤100 字/页且要点 ≤4 条；阅读/汇报 ≤200 字、≤6 条；
  封面结尾放宽 ×1.4。口播备注 = 要念的稿子，**40–260 字（约 15–60 秒）**，口语短句；
  从文章改写时备注保留作者原句、屏上字从备注反提炼。
- **结尾页写"谢谢观看"= WARN**——结尾放结论或行动号召，正则 `谢谢(观看|收听)?|Thanks?|Q&A`。
- 同页型连现三次 WARN；超 15 页缺章节页 WARN。
- **容量驱动选版式**：34 个版式各有（条数区间， 每字段字数上限）表，写完大纲立即
  核对；超容量**自动换候选链下一个版式**并写"想要 X 换成 Y 因为超容量"的审计记录；
  用户手动锁定版式时超容也不换，只写警告留人决断。
- 页数估算：按字数/每页字数 + 2（封面结尾），范围 [0.8m, 1.2m]；每个 H2 至少一页。

## 五、动画与降级（简要）

- **动画语义标签**：版式产元素时打 `step` 组号，构建期按组写 PowerPoint 原生
  时序（逐条点击/自动间隔 320ms）；标题/背景/页眉恒在。**场景定默认**：口播/
  讲课=逐条点击出现，汇报/阅读=仅翻页——不问就不加。表格和图表是原生对象只能
  整页出。QA：动画指向不存在的形状=ERROR。
- **渲染降级链**：LibreOffice 缺失时按排版数据直接画**近似预览**（同折行逻辑，
  溢出照样能看出来），交付时声明"预览是近似图"；生图模型不可用时不静默降级——
  问用户（接模型/搜可商用图库/用户素材/程序化插画），AI 出图失败的页自动落
  程序化插画并在交付时**如实说明哪几页是兜底图，不说成 AI 生成**。
- 公式保真：PowerPoint 公式对象（OMML）解析器读不到、渲染器画不出（页面上留洞）
  ——就地线性化成普通文本 run（上下标→Unicode、分式→(a)/(b)、保留字号颜色），
  公式保持可编辑；公式多的讲解页用专用页型，同页所有公式统一取最小字号。
